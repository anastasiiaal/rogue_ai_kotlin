# 🧠 RogueAI

**RogueAI** is a cooperative real-time Android game inspired by *Spaceteam*, where players must work together to contain an unstable artificial intelligence under pressure.

Players interact with a control console, execute commands, and communicate verbally to survive escalating AI threats.

---

## 🎮 Game Concept

- Cooperative game (Solo & Multiplayer)
- Real-time instructions generated by an AI
- Each player sees **different controls**
- Verbal communication between players is required
- Incorrect or late actions increase the global threat level

**Goal:** keep the AI threat below the critical level until the end of the game.

---

## 🏗️ Technical Stack

- **Language:** Kotlin  
- **UI:** Jetpack Compose  
- **Architecture:** MVVM + Repository pattern  
- **Networking:**
  - WebSocket (OkHttp) for real-time gameplay
  - REST API (OkHttp) for room creation and joining
- **Asynchronous handling:** Kotlin Coroutines
- **State management:** StateFlow

---

## 🧩 Architecture Overview

The application follows a clean **MVVM architecture**:

```
UI (Jetpack Compose)
↓
ViewModel
↓
Repository
↓
Network (WebSocket / REST)
```

### Key principles
- UI is reactive and stateless
- ViewModels manage screen state and lifecycle
- Repositories encapsulate data access
- Network layer is strictly I/O (no UI or game logic)

---

## 🔄 Lifecycle & Real-Time Handling

- Jetpack Compose recomposition is handled safely using `LaunchedEffect`
- ViewModels survive recompositions and clean up resources in `onCleared`
- A shared WebSocket connection is used for multiplayer sessions
- StateFlow propagates real-time game updates across the app

## 🎨 UI & Design System

- Interface inspired by **control panels / operator consoles**
- Custom design system:
  - `RoguePalette` for colors
  - Custom reusable buttons and cards
- Reusable UI components:
  - `CommandCard`
  - `SliderCommandView`
  - `ToggleCommandView`
- Visual feedback for instructions and selected commands

## 🚀 Getting Started

### Prerequisites
- Android Studio
- Android SDK 26+
- Internet connection (backend required)

### Run the app
1. Clone the repository
2. Open the project in Android Studio
3. Run on an emulator or physical device
4. Create or join a game room

## 📁 Project Structure

```
ui/ → Jetpack Compose screens & UI components
ui/viewmodel/ → ViewModels (screen logic & lifecycle)
data/ → Repositories (data access layer)
network/ → WebSocket & REST clients
model/ → Game and room data models
theme/ → Design system (colors, buttons, styles)
util/ → Utility helpers (room code validation, etc.)
```
